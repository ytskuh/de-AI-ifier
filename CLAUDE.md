## Environment and Tooling

- Use `uv` and `pyproject.toml` to manage dependencies, virtual environments and run scripts.
- proxy is set in env for tasks that require internet access. Exceptions: do not use proxy for ssh connection, and cloudflare r2 access.

## Documents

The default document language is English.

`docs/<subfolder>/{YYYY}-{MM}-{DD}-<name>.md`
### Template:

```markdown
---
title: [Title]
type: [feat|fix|refactor|...]
status: active
date: YYYY-MM-DD

# composition_mode:
# - human_led: primarily written and decided by a human.
# - human_curated: may start from AI output, but has been substantially edited, verified, and accepted by a human as source-of-truth material.
# - ai_generated: generated by AI with limited human intervention; treat as draft/reference only.
# This field can be changed, e.g. ai_generated documents may be lifted to human_curated after extensive modification.

composition_mode: [human_led|human_curated|ai_generated]
origin: docs/brainstorms/YYYY-MM-DD-<topic>-requirements.md # include when planning from a requirements doc
deepened: YYYY-MM-DD # optional, set when the confidence check substantively strengthens the plan
---

[Contents]

```

### Document rules

 - Treat `README.md` and `docs/design` as source of truth. Design changes are written to the design doc BEFORE implementing them, based on the agreed decisions (not reverse-engineered from code); thereafter the design doc is kept consistent with the code — any change that would make them diverge updates both in the same change.
 - Persistent document researches and external material in `docs/reference`, brainstorms in `docs/brainstorm` and plans in `docs/plan`
